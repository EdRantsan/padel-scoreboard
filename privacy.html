Local Data Storage

The Application is designed with privacy at its core. Your core match records, customized player names, scores, training logs, and personal settings are stored locally on your device using on-device storage. The Service Provider does not require account creation or personal login credentials to use the Application.

Third-Party Services and Automatically Collected Data

To diagnose technical crashes, monitor application performance, and understand aggregate feature adoption, the Application integrates backend telemetry services provided by Google Firebase (Google LLC). When using the Application, certain diagnostic and technical information is automatically collected and processed:

1. Crash Diagnostics (Firebase Crashlytics)

  • Stack traces and error logs associated with crashes or unexpected exceptions.
  • Device metadata (device model, manufacturer, operating system version, available storage, and device orientation at the time of a crash).
  • Application version and build number.
  • Purpose: Resolving software bugs, preventing regressions, and ensuring app reliability.

2. Usage Analytics (Google Analytics for Firebase)

  • Pseudonymous identifiers (such as Firebase Installation IDs / Instance IDs).
  • Aggregated interaction events (e.g., match format selected, set counts, duration brackets, backup export/import triggers, theme/language preferences).
  • Screen navigation flows (screens viewed without personal inputs).
  • Purpose: Understanding feature popularity and improving the user experience. No personal player names or private match notes are sent to analytics.

3. Performance Monitoring (Firebase Performance Monitoring)

  • Application startup time, screen rendering latency, and background responsiveness.
  • Purpose: Identifying performance bottlenecks and optimizing render performance.

For more details on how Google processes telemetry data, please review:

  • Google Privacy Policy
  • Firebase Privacy & Security Information

Data Retention

  • Crash Diagnostics: Crashlytics retains crash events and diagnostic stack traces for 90 days, after which they are automatically deleted.
  • Analytics Data: Aggregated event data is retained in accordance with standard Google Analytics retention windows (up to 14 months).
  • Local Match Data: Retained on your device indefinitely until you manually clear app data or uninstall the Application.

Data Transfers and Security

All telemetry data sent to Google Firebase is encrypted in transit using industry-standard Transport Layer Security (TLS/HTTPS). Google adheres to standard data processing agreements for European Economic Area (EEA) data transfers.

Location and AI Technologies

The Application does not request or track your device's precise real-time GPS location. The Application does not use Artificial Intelligence (AI) algorithms to profile or process personal data.

Children's Privacy

The Application is not directed toward children under the age of 16. The Service Provider does not knowingly collect personally identifiable information from children.
